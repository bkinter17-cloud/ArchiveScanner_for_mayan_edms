# 🗂 برنامج أرشيف المستندات
### نظام أرشفة المستندات الرقمية المتكامل

---

## نظرة عامة

**برنامج أرشيف المستندات** هو تطبيق سطح مكتب يعمل على نظام Windows ويتكامل مع نظام إدارة المستندات الإلكترونية خادم الأرشيف الرقمي عبر واجهة برمجية متقدمة، يُتيح للمستخدمين:

- **المسح الضوئي** للمستندات مباشرةً من أجهزة Twain/WIA
- **تحميل ملفات PDF** وأرشفتها في قواعد البيانات
- **البحث السريع** عن المستندات المحفوظة وتنزيلها

---

## المميزات

| الميزة | الوصف |
|---|---|
| 🖨 مسح ضوئي مباشر | دعم كامل لأجهزة Twain/WIA عبر NAPS2 |
| 📄 تحميل PDF | أرشفة ملفات PDF الجاهزة بنقرة واحدة |
| 🔍 بحث متقدم | بحث بالرقم أو العنوان أو الكلمة المفتاحية |
| 🌐 خادم مرن | تخصيص عنوان الخادم عند التثبيت أو تسجيل الدخول |
| 💾 حفظ تلقائي | يُحفظ عنوان الخادم وإعدادات الاتصال تلقائيًا |
| 🔒 مصادقة آمنة | تسجيل دخول عبر Token API الخاص بخادم الأرشيف |

---

## متطلبات التثبيت

- نظام Windows 10/11 (64-بت)
- اتصال بشبكة تحتوي على خادم الأرشيف الرقمي نشط
- حساب مستخدم بصلاحية أرشفة المستندات على الخادم

> لا يلزم تثبيت Python أو أي مكتبات إضافية؛ البرنامج يحتوي على جميع المتطلبات.

---

## التثبيت

1. قم بتشغيل `ArchiveScanner-Setup-AR.exe`
2. أدخل عنوان URL لخادم الأرشيف الخاص بمؤسستك  
   (مثال: `http://192.168.1.100:8000`)
3. أدخل معرّف نوع المستند الافتراضي (عادةً `4`)
4. أكمل التثبيت واضغط **إنهاء**

---

## الاستخدام

### أرشفة مستند
1. أدخل بيانات الاعتماد وسجّل الدخول
2. انتقل إلى تبويب **أرشفة جديدة**
3. أدخل رقم المستند والموضوع والتاريخ
4. اختر نوع المستند وجهاز الماسح
5. اضغط **مسح وأرشفة** أو **اختيار وتحميل PDF**

### البحث في الأرشيف
1. انتقل إلى تبويب **البحث في الأرشيف**
2. اكتب رقم المستند أو كلمة مفتاحية
3. انقر مزدوجًا على النتيجة لتنزيل المستند وفتحه

## بنية المشروع

```
ArchiveApp/
├── archive.py              # الواجهة الرئيسية للتطبيق
├── core.py                 # منطق الأعمال وعميل API
├── assets/
│   ├── logo.png            # شعار التطبيق
│   └── logo.ico            # أيقونة التطبيق
├── build_assets/
│   └── NAPS2/              # محرك المسح الضوئي (مُضمَّن)
├── ArchiveScannerQt.spec   # إعداد PyInstaller
└── ArchiveScannerQt.iss    # نص المثبّت (Inno Setup)
```

---

## البناء من المصدر

```bash
# تثبيت المتطلبات
pip install -r qt6_windows_requirements.txt

# بناء الحزمة القابلة للتوزيع
pyinstaller ArchiveScannerQt.spec

# (اختياري) إنشاء حزمة المثبّت عبر Inno Setup
iscc ArchiveScannerQt.iss
```
